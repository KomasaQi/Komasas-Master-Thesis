
\section*{第7章 结论}
当前，基于云控的城市路口通行优化研究仍存在若干关键不足，包括面向城市道路场景的云控基础平台整体架构缺失、单一路口混合交通环境下难以统一刻画交通信号与车辆轨迹耦合关系、非理想通信条件下难以保证协同控制的安全性与高效性，以及现有方法难以扩展至连续多路口场景。针对上述问题，本文首先面向城市道路场景，研究了云控基础平台分层解耦架构设计方法，创建了面向城市道路的云控基础平台参考架构，并进一步建立了云控基础平台城市路口通行优化场景参考架构，形成了相应的总体技术方案；随后，围绕单一路口场景，提出了基于车辆延误估计模型的单一路口交通信号与智能网联车辆协同优化方法，通过构建车辆延误估计模型和启发式并行树搜索算法，实现了动态混合交通流下最优信号方案和车辆轨迹的高效协同求解；进一步，针对时变时延与丢包条件，通过路口车辆状态估计、考虑车辆状态不确定性的协同优化以及鲁棒预测控制，实现了非理想通信条件下的安全协同优化；在此基础上，面向连续多路口场景，提出了基于连续路口到达-驶离模型的多路口交通信号与智能网联车辆协同优化方法，构建了连续路口信号-车辆双层协同优化框架，并设计了相应的高效求解算法与分布式异步更新机制；最后，基于云控微缩沙盘平台设计了单路口和连续路口试验场景以及非理想通信模块，对所提方法的有效性与实时性进行了验证。通过上述研究，本文得到如下主要结论。

\begin{enumerate}[itemsep=2pt, parsep=0pt]
    \item 针对城市道路场景下云控基础平台整体架构缺失的问题，提出了以功能场景驱动的、“自上而下”与“自下而上”相结合的云控基础平台架构设计方法，创建了面向城市道路的云控基础平台一致的、统一的、可扩展的参考架构，为云控基础平台在不同城市道路功能场景下的设计、开发与部署提供了顶层指导。该架构设计方法参考基于模型的系统工程MBSE思想，由云控基础平台共性基础能力体系和三级云分层结构出发，“自上而下”形成参考架构设计的先验准则；在此基础上，面向若干城市道路典型功能场景开展参考架构设计，并通过“自下而上”的归纳整合集成，最终形成面向城市道路的云控基础平台参考架构，系统刻画了平台内外部分层解耦的层级组织、功能逻辑及数据流关系。
    \item 针对基于云控的城市路口通行优化场景缺乏顶层架构指导、难以统筹功能逻辑与技术实现路径的问题，建立了云控基础平台城市路口通行优化场景参考架构，为开展相关方法研究提供了架构层面的指导。该参考架构以云控基础平台整体功能逻辑架构为基础，结合城市路口通行优化场景的业务需求与运行特征，系统梳理了该场景下云控基础平台内部涉及的功能模块、逻辑组件及其数据流关系，并在此基础上进一步结合该场景具体技术内容，形成了面向城市路口通行优化场景的云控基础平台总体技术方案，为各项关键方法的模块化组织、接口衔接与系统集成提供了清晰的技术主线。
    \item 现有研究难以刻画信号方案与车辆轨迹之间耦合关系以致无法支撑单一路口信号-车辆协同优化，本研究提出了综合考虑ICV与HDV轨迹的车辆延误估计模型，为单一路口协同优化问题的精确描述与求解提供了模型基础。该模型基于极小值原理和几何分析建立了ICV的解析轨迹规划子模型，并建立了考虑信号灯影响的HDV轨迹生成子模型，从而构建了给定信号方案相关参数与车辆轨迹以及车辆延误之间的解析关系，在建模层面贯通了信号方案决策与车辆微观运行过程，最终将单一路口信号-车辆协同控制建模为一个混合整数非线性规划(MINLP)问题。
    \item 现有研究难以兼顾动态混合交通流下信号-车辆协同优化算法的最优性与实时性，本研究提出了启发式并行树搜索算法，实现了动态混合交通流下最优信号方案和车辆轨迹的高效协同求解。该算法利用所建MINLP问题的结构特性以及车辆延误估计模型的解析特性，研究了合理的搜索树结构和并行搜索机制，实现对各车道级子问题的高效协同求解，从而完成了对原问题全局最优解的高效搜索。
    \item 针对在通信时延与丢包并存条件下难以保证云端获取路口车辆状态的时效性与准确性问题，提出了基于OOSM-UKF的路口车辆状态估计方法，提高了非理想通信条件下云端获取路口多车状态的可用性与精准度。该方法针对非理想通信条件下乱序测量对状态估计一致性与精度的影响，在无迹卡尔曼滤波框架内构建了车辆状态的回放更新机制，并将控制量信息与位置次序先验共同纳入估计过程，从而实现了云端对控制区内多车状态均值及其不确定性的实时、准确获取。
    \item 现有研究难以刻画车辆状态不确定性对信号-车辆协同优化问题的影响，本研究提出了考虑车辆状态不确定性的路口协同优化方法，实现了对该问题中状态不确定性的显式建模与最优信号方案和车辆轨迹的鲁棒求解。该方法以所提路口车辆状态估计方法的输出为基础，通过均值锚定轨迹将车辆状态不确定性传播至驶离时刻不确定性，并进一步将其引入车辆驶离判定与节点代价计算过程，使优化求解能够显式建模车辆状态不确定性对路口运行过程的影响，最终生成对不同程度非理想通信条件具有较强适应性的最优信号方案和车辆轨迹。
    \item 针对在通信时延与丢包并存条件下难以保证云端对路口各ICV轨迹控制的精确性与安全性问题，提出了基于tube-MPC的鲁棒预测控制方法，在保证鲁棒安全性的前提下提升了ICV的轨迹跟踪性能。该方法通过估计状态误差的上下界，将车辆实际状态约束于名义状态范围内的管道(tube)中，并以此刻画通信时延与丢包作用下系统状态的可能演化范围，使得ICV实际轨迹能够在各种非理想通信条件下满足给定约束，从而在确保安全的前提下增强了轨迹跟踪控制的准确性和平滑性。
    \item 现有信号-车辆协同优化方法无法直接应用于连续多路口场景，本研究提出了连续路口信号-车辆双层协同优化框架，有效融合了多路口间信号协调控制与单路口内信号-车辆协同优化。该框架将连续路口场景下的信号协调问题与单路口信号-车辆协同优化问题进行分层解耦，上层面向连续路口进行自适应信号协调，下层依托分布式异步更新机制对各路口的信号方案与ICV轨迹进行进一步优化调整，从而实现了连续路口信号方案的自适应协调与ICV轨迹的协同优化，提升了连续路口场景的整体通行效率。
    \item 现有研究中缺乏对相邻路口间的信号方案与交通流动态关联关系的刻画导致难以支撑连续路口信号方案动态优化，本研究提出了连续路口到达-驶离模型，建立了路口间信号方案与交通流传播过程的关联机制。该模型基于上游路口的车辆驶离情况及其信号方案构建下游路口的累计到达曲线，进而建立路口行驶延误与各路口信号方案之间的数学模型，能够从交通流时空传播角度统一表征相邻路口间的联动效应，为连续路口信号协调优化问题的精确描述与求解提供了模型支撑。
    \item 针对连续路口自适应信号协调问题参数维度高、求解难度大的难题，提出了基于分块坐标下降的启发式求解算法，提高了该高维复杂优化问题的可解性和求解效率。该算法通过设计合理的分块策略，将原始的高维复杂问题划分为多个相互关联的子问题，并采用迭代式分块寻优机制对各子问题进行交替更新与逐步收敛，在控制计算复杂度的基础上，高效求解连续路口的最优参考信号方案。
    \item 搭建了面向连续路口通行优化场景的仿真平台，全面系统地验证了所提方法在提升交通效率方面的有效性。仿真结果表明，所提基于车辆延误估计模型的交通信号-智能网联车辆协同优化方法在不同车流量和ICV渗透率的组合工况下，均能够有效降低单一城市路口的平均行驶延误，提升路口交通效率，且在不同非理想通信条件下，均能够保证车辆行驶安全性，并降低通行延误，提升路口效率；所提基于连续路口到达-驶离模型的多路口交通信号-智能网联车辆协同优化方法在不同车流量和ICV渗透率的组合工况下，均能够有效降低连续路口的平均行驶延误并提升平均速度，从而提升连续路口的整体交通效率。
    \item 基于云控微缩沙盘平台设计了单路口和连续路口的试验场景以及非理想通信模拟模块并进行了相应的试验，对所提方法的有效性与实时性进行了验证。沙盘试验结果表明，所提基于车辆延误估计模型的交通信号-智能网联车辆协同优化方法能够实现单一路口的协同优化，且在非理想通信条件下仍能够实现路口安全协同；所提基于连续路口到达-驶离模型的多路口交通信号-智能网联车辆协同优化方法能够实现对连续路口信号方案的自适应协调和ICV轨迹的协同优化；且上述三个方法均能够在一个控制周期内完成优化计算，满足实际应用的实时性要求。
\end{enumerate}

\subsection*{本文的创新之处}
本文的创新之处主要在于以下三点。
\begin{enumerate}[itemsep=2pt, parsep=0pt]
    \item 创建了面向城市道路场景的云控基础平台参考架构。针对城市道路场景下云控基础平台整体架构缺失、难以支撑车路云系统一体化设计的难题，本研究提出了以功能场景驱动的、“自上而下”与“自下而上”相结合的云控基础平台架构设计方法，创建了面向城市道路的云控基础平台一致的、统一的、可扩展的参考架构，用数字化模型对云控基础平台的结构组成、功能逻辑与数据流关系进行了系统刻画，突破了面向城市道路的云控基础平台多主体、多层级、多场景难以协同描述与融合设计的瓶颈，为云控基础平台在城市道路场景下的体系化设计、功能扩展与应用开发提供了顶层指导。
    \item 提出了基于车辆延误估计模型的单一路口交通信号与智能网联车辆协同优化方法。现有研究在进行单一城市路口交通效率优化时，难以统一刻画信号方案与车辆行驶轨迹之间耦合关系，且难以在时变时延和丢包条件下保证路口的安全性和通行效率。本研究提出了车辆延误估计模型，能够综合考虑路口信号灯对ICV轨迹可行域的约束和对HDV纵向行驶过程的影响，建立了车辆行驶延误与信号方案之间的解析关系，从而破解了现有方法对信号方案-车辆轨迹耦合关系难以刻画的瓶颈；在此基础上提出了路口车辆状态估计方法、考虑不确定性的协同优化方法和ICV鲁棒预测控制方法，形成了面向非理想通信条件的信号-车辆一体化建模、优化与控制策略，在保障安全的前提下提升了路口通行效率。
    \item 提出了基于连续路口到达-驶离模型的多路口交通信号与智能网联车辆协同优化方法。现有信号-车辆协同控制方法缺乏对路口间交通流传播与信号方案耦合关系的刻画，难以支撑连续多路口的通行优化。本研究提出了连续路口到达-驶离模型，依据上游路口在给定信号约束下的驶离车流对下游路口车辆到达过程进行建模，并在此基础上建立车辆行驶延误与各路口信号方案之间的关联关系，从而突破了连续路口间信号方案与交通流动态耦合关系难以显式建模的制约；在此基础上构建了连续路口双层协同优化框架和分布式异步更新机制，形成了面向连续多路口场景的信号-车辆分层协同优化方法，有效提升了连续路口系统的整体通行效率。
\end{enumerate}

\subsection*{未来研究方向}
本文针对混合交通下基于云控的城市路口交通信号与智能网联车辆协同优化方法研究取得了一定成果，但仍存在需要进一步深入研究之处，未来的研究方向主要包括如下三点。
\begin{enumerate}[itemsep=2pt, parsep=0pt]
    \item 充分考虑实际应用中存在的更多非理想因素，例如天气影响、路面状况影响、交通事件影响、人类驾驶员不确定性影响等，研究在这些因素影响下的单路口和连续路口交通信号与智能网联车辆协同优化方法，提升所提方法在实际应用中的适用性和鲁棒性。
    \item 进一步推广至更广域的城市路网场景，研究基于道路拓扑和交通流参数的区域划分机制，以及云端的分布式计算机制，实现对于大规模城市路网交通效率的优化。
    \item 在云控微缩沙盘平台对方法有效性和实时性验证的基础上，进一步依托相关智能网联云控示范区，在真实道路环境下开展实车试验，在实际应用场景中验证所提方法的功能与性能。
\end{enumerate}
